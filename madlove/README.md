# MAD LOVE — Hollow Ward REC

**A Scroll Entertainment Original** · SCP-1388-KO · S01 E01 *Hollow Ward*

크랙 스토리 「매드러브」 연동 단서 탐색 페이지. 캠코더를 들고 폐병원을 돌아다니며 단서를 녹화하고, 찾은 코드를 크랙에 입력해 이야기를 진행한다.

- 마우스 드래그 / 모바일 기울이기로 둘러보기
- 길게 누르거나 `R` 키로 녹화
- 데스크톱 · 모바일 모두 지원

> 식인, 신체 훼손, 심리적 공포 묘사가 포함되어 있습니다.
