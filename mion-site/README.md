GL · 기원불명 인외 · 혐관 · 여름방학 귀향 호러로맨스

6년 만에 고향 온계읍에 내려온 당신이, 자기가 손절했던 애를 다시 만나는 이야기.
그 소개 페이지.

---

## 보기

정적 페이지 하나라 빌드 과정이 없다.

```bash
# 로컬에서 볼 때
python3 -m http.server 8000
# → http://localhost:8000
```

`file://`로 바로 열어도 대부분 동작하지만, 브라우저에 따라 오디오 자동 재생이 막힌다.
간단한 서버로 띄우는 쪽이 정확하다.

### GitHub Pages

Settings → Pages → Source를 이 저장소의 브랜치 루트로 지정하면 끝.
`.nojekyll`이 있어서 Jekyll 처리를 타지 않는다.

## 동작하는 것들

- **진입 관문** — 포스터를 눌러야 들어간다. 그 클릭이 배경음 재생 제스처를 겸한다.
  꽃말이 「사랑 그리고 저주」이고, 그 꽃을 건드리면 저주가 된다는 전승을 따른 구조다.
- **먹물** — 화면 위에서 맺혀 늘어지다 끊겨 떨어진다. 떨어진 자리에는 **자국이 남고 지워지지 않는다.**
  작품 안의 「동화」가 불가역인 것과 같은 규칙이다. 최대 14개까지만 유지한다.
- **촉수** — 이미지 한 장을 16마디로 잘라 중첩시키고 각도를 누적해 휘게 한다.
  종이 위에서는 `multiply`로 깔려 번진 먹처럼 읽힌다.
- **꽃** — 5단 원근. 크기·농도·블러·흔들림 폭을 깊이에 따라 같이 바꾼다.
  스크롤하면 좌우로 갈라진다.
- **세로 괘선과 붉은 사각형** — 포스터의 그 선이다. 사각형이 스크롤 진행도를 따라 내려오고
  **한 번 내려가면 올라오지 않는다.**
- `prefers-reduced-motion`을 켜 둔 환경에서는 애니메이션이 전부 정지한다.
