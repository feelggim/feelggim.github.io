# 이윤 : 홍연 · 紅緣

크랙 GL 스토리 「이윤 : 홍연」 소개 홈페이지.

## GitHub Pages로 올리기
1. 이 폴더 안의 파일 전체(index.html, img, audio)를 저장소 루트에 올린다
2. 저장소 Settings → Pages → Branch를 `main` / `/ (root)`로 저장
3. 몇 분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열린다

## 크랙 링크 걸기
index.html 에서 `var CRACK_URL='';` 를 찾아 따옴표 안에 크랙 작품 주소를 넣으면 마지막 장 버튼에 걸린다.
