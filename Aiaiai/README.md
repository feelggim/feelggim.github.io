# AI AI AI — 사랑, 사랑, 사랑

단편 롤플레잉 「AI AI AI」 소개 페이지. 모델명 **ADAM-ØØ**.

> 사람은 그것을 사랑이라 불렀고, AI는 그것을 데이터라 불렀다.
> 둘은 같은 것을 가리키고 있었다.

---

## 올리는 법 (GitHub Pages)

1. 새 저장소를 만든다.
2. 이 폴더 안의 것을 **통째로** 저장소 루트에 올린다.
   `index.html` 이 루트에 있어야 한다.
3. 저장소 → **Settings → Pages → Source: Deploy from a branch**
   → 브랜치 `main`, 폴더 `/ (root)` → Save.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열린다.

빌드 과정이 없다. 정적 파일 그대로 올리면 된다.

## 동작하는 것

- 진입 시 권한 이양 확인창 (3초 카운트 → "거절하지 않으셨습니다")
- 배경 코드 레인 / 심전도 배너 (박자마다 한 글자씩, 가끔 평평해짐)
- 제1원칙 섹션 — 사랑의 말이 새어 나왔다가 정정되는 글리치
- 19금 게이트, 엔딩 스포일러 카드
- **06-1 정지** — 스트리밍 중 아무 때나 끊는 인터랙션
- 하단 아이 대화창 (고정 응답 + 정지 버튼)

## 알아둘 것

- **배경음은 자동 재생되지 않는다.** 브라우저 정책이라 첫 확인창의 버튼을
  누르는 순간 재생된다. 우측 하단 버튼으로 껐다 켤 수 있다.
- 하단 대화창은 미리 써 둔 아이의 발화에서 회신한다.
  실시간 AI 응답이 필요하면 별도 API 프록시를 붙여야 한다.
- 폰트는 Google Fonts에서 Noto Sans KR / Noto Serif KR / IBM Plex Mono / Syncopate를
  불러온다. 오프라인에서는 대체 폰트로 표시된다.
- 다크 모드를 쓰지 않는다. 흰 배경 고정이다.
