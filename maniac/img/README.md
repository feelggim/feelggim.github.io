# RAINBOW：MANIAC · 박주은

크랙 스토리 「RAINBOW：MANIAC」 공식 홈페이지. 패션 매거진 한 권과 박주은의 가상 인스타그램.

- `index.html` 매거진 (입장 → 넘기기, 데스크탑은 오른쪽 폰에서 노래·인스타)
- `feed.html` 박주은 인스타그램 (뒷면 스위치: 새벽 4시의 진짜 업로드)
- `tap.html` 가사 싱크 도구. 결과를 `lyrics.js`에 통째로 붙여 넣으면 가사가 뜸
- `lyrics.js` 가사 타이밍

이 페이지는 픽션입니다. 등장하는 인물·회사·계정·기사는 모두 가상입니다.
